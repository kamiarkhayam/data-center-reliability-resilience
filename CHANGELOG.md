# Changelog

## 0.2.0 — Reliability and resilience revision

- Reframed the software title, README and citation metadata around community adequacy and emergency support.
- Added portable audited site-level generator/fuel/UPS, exact supply-adequacy, fixed-repair hurricane and chronological internal-service implementations.
- Added incremental export-enablement economics and optional frozen-policy support-responsive evaluation.
- Added explicit input-bundle preparation, source hashes and numerical regression checks.
- Kept the public release limited to code, configurations, provenance and synthetic fixtures; research outputs and manuscript artifacts are excluded.
- Retained earlier RL benchmarks, E12/E24 controller and fiscal workflows as clearly labeled legacy material.

The new default support model uses three independent 5 MW connections, stochastic equipment and retained internal fuel. It does not reinterpret E12/E24 hours as fuel reserves. The repository uses the reliability/resilience name; Python package and import names remain unchanged.
